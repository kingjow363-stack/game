# EXO Industries

개인용 싱글 플레이 증분 전략 게임의 프로토타입입니다. Evolve에서 영감을 받은 단계별 발전을 바탕으로 독자적인 산업·정복 흐름을 구성했습니다.

## 진행

광석 클릭 채굴 → 발전소 → 산업 자동화 → 합금 공장·연구소 → 행성 물류망 → 지구 산업권 통합 → 성간 항법·조선소 → 달·화성·목성 → 태양계 → 알파 센타우리 → 은하 패권.

- 지구 광석은 20,000으로 한정됩니다. 달을 확보하면 외계 자원을 무한 채굴합니다.
- 공장은 원료와 에너지가 부족하면 생산을 멈춥니다.
- 환생 시 이번 우주의 정복 영토 수의 제곱 + 완료한 연구 수만큼 영구 포인트를 받습니다. 포인트당 전체 생산량 +10%입니다.
- 환생은 자원·시설·연구·영토를 초기화하고 영구 포인트·환생 횟수·누적 정복 수를 유지합니다. 정복 전에도 완료한 연구만큼 보상을 받습니다.
- 자동 저장과 최대 8시간 오프라인 생산을 지원합니다.
- 현재 정복은 자원과 함대 비용을 지불하는 방식이며 전술 전투는 구현하지 않았습니다. 경제 밸런스는 초기값입니다.

## v0.3 개선 사항

- 시설별 가동 수 조절, 초당 순수지와 부족 원료·가동률 표시
- 건설 예약 8칸: 자원이 모이면 예약 순서대로 현재 가격에 건설, 언제든 취소 가능
- 시작 단계와 전력 부족에 맞춘 다음 목표 안내
- 영구 기술: 개척 보급품(다음 환생 시작 자원), 정밀 공정(투입 절감), 기술 아카이브(연구 비용 절감)
- 포인트를 기술에 사용해도 누적 획득 포인트의 생산 보너스 유지
- 설정에서 JSON 저장 내보내기/불러오기, 손상된 데이터 보존과 정상 자동 백업 복원
- 일시정지는 재접속 후에도 유지되며 자동 생산·오프라인 생산·건설 예약을 함께 멈춤
- 기존 v0.2 저장 자동 이전. 업데이트 전 저장을 파일로 백업하고 이전 버전을 종료하세요. v0.3부터는 같은 저장 프로필을 사용하는 창이 중복 실행되지 않습니다.

공장은 기본적으로 채굴 → 발전 → 합금 → 연구 → 함대 순서로 원료를 소비합니다. 상단의 초당 수지는 현재 재고로 다음 1초를 계산한 값이므로 재고가 고갈되면 달라집니다. 에너지를 비축하려면 발전소를 늘리거나 소비 시설의 가동 수를 줄이세요.

참고 자료와 변경 근거: [검토 기록](docs/research-v0.3.md).

## Windows 실행 파일

GitHub에서 다운로드하려면:

1. [Windows game download](https://github.com/kingjow363-stack/game/actions/workflows/windows-build.yml)를 엽니다.
2. 초록색 체크가 표시된 최신 실행을 선택합니다.
3. 페이지 아래 **Artifacts → EXO-Industries-Windows**를 클릭합니다. 다운로드하려면 GitHub 로그인이 필요합니다.
4. 받은 ZIP 파일을 풀고 안의 `.exe`를 실행합니다.

빌드 파일은 30일 동안 보관됩니다. 만료된 경우 Actions에서 **Run workflow**로 다시 만들 수 있습니다.

`dist/EXO-Industries-0.3.0-Windows.exe`를 실행합니다. 별도 서버나 인터넷 연결은 필요 없습니다. 개인용 미서명 실행 파일입니다.

저장 데이터는 Windows의 `%APPDATA%/exo-industries/` 아래 Electron 사용자 데이터에 보관됩니다. EXE를 이동해도 같은 Windows 사용자라면 저장 데이터를 유지합니다. 앱 안의 ‘진행 초기화’는 영구 기록까지 삭제합니다.

직접 Windows에서 빌드하려면 Node.js를 설치한 뒤:

```sh
npm ci
npm run dist:win
```

## 개발

```sh
npm ci
npm start
npm test
```

데스크톱 개발 실행에는 그래픽 디스플레이가 필요합니다. 클라우드에서 UI를 검증할 때는 `python3 -m http.server 8000 --bind 0.0.0.0`으로 같은 화면을 제공할 수 있습니다. 브라우저와 데스크톱의 저장 데이터는 별개입니다.
