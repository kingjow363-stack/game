# v0.3 개선 근거와 검증 범위

검토일: 2026-10-06. Evolve의 기능 설명을 참고해 EXO의 기존 경제 모델에 맞게 독자적으로 구현했다. 원본 코드·그림·문구를 게임에 복사하지 않았다.

## 실제로 확인한 자료

- 사용자 제공 [공식 위키 변경 기록](https://pmotschmann.github.io/Evolve/wiki.html#changelog): 웹 페이지 요청은 403으로 거부되었다. 동일 위키를 생성하는 [공식 저장소 change.js](https://github.com/pmotschmann/Evolve/blob/3436358dcd03d9f9e071d51ea071e0a78c0322e4/src/wiki/change.js) 원문을 읽었다.
- 해당 커밋의 최신 기록은 1.4.10 (2026-06-19). 최신 패치 자체는 계절 이벤트 수정이다. 이번 변경을 그 패치의 재현이라고 주장하지 않는다.
- 1.4.9: 자원 상태 표시 개선. 1.3.13: 건설 대기열 설정 확장. 1.3.11: 전력 설정 개선. 더 과거의 기록에는 낮은 전력 상태와 예약 자원 표시 개선이 있다.
- [기본 진행 설명](https://github.com/pmotschmann/Evolve/blob/3436358dcd03d9f9e071d51ea071e0a78c0322e4/src/wiki/basics.js): 단계별 문명 발전, 자원 생산, 첫 리셋 안내.
- [환생 위키 구성](https://github.com/pmotschmann/Evolve/blob/3436358dcd03d9f9e071d51ea071e0a78c0322e4/src/wiki/prestige.js) 및 [환생 자원 설명](https://github.com/pmotschmann/Evolve/blob/3436358dcd03d9f9e071d51ea071e0a78c0322e4/src/wiki/p_res.js): 리셋·영구 자원·업그레이드를 구분하는 구조.
- 나무위키의 Evolve 문서 접근은 403으로 거부되었다. 본문을 확인하지 못했으므로 나무위키 기반 변경이라고 표시하지 않는다. 사용자가 정확한 문서 링크나 본문을 제공하면 별도 검토가 필요하다.

## EXO에서 찾은 문제와 수정

| 기존 문제 | v0.3 변경 |
| --- | --- |
| 모든 공장이 항상 켜져 있어 원료 비축이 어려움 | 시설별 가동 수 조절, 전체 가동/중지 |
| 자원이 늘지 않는 이유가 보이지 않음 | 초당 순수지, 시설 가동률, 부족 원료 표시 |
| 건설 버튼을 계속 확인해야 함 | 자원을 미리 차감하지 않는 FIFO 예약 8칸과 취소 |
| 시작부터 먼 목표인 지구 지배만 표시 | 채굴기→발전소→연구→합금→연구소→전력 여유→영토의 다음 행동 안내 |
| 환생은 단일 배율뿐이며 첫 정복 전 성과가 사라짐 | 연구 수 + 정복 수² 보상, 포인트 소비와 생산 보너스 분리, 영구 기술 3종 |
| 일시정지를 해도 다시 열면 오프라인 생산됨 | 일시정지 저장과 복원, 예약·생산 함께 정지 |
| 매초 전체 화면을 다시 만들어 버튼 포커스가 사라짐 | 수치만 갱신하고 시설·기술 등 구조가 바뀔 때만 목록 갱신 |
| 손상된 저장을 조용히 빈 데이터로 덮어쓸 위험 | 스키마 검증·자동 백업·손상 원본 보존·JSON 내보내기/불러오기 |

## 검증

경제·저장 테스트: 초기 자원 주입 없이 달 도달, 유한 지구 자원, 예약 가격과 순서, 투입 제한, 원료 절감, 이전 저장 이전, 잘못된 저장 거부, 일시정지, 시계 역행, 오프라인 상한, 영구 기술과 환생 보상.

화면 확인: 실제 버튼 클릭·가동 변경·예약과 취소·내보내기/불러오기·환생·이전 상태 재접속·손상 저장 보존·모든 탭의 모바일 가로 넘침·페이지 오류 여부.

현재 정복은 자원과 함대를 소모하는 단계형 진행이다. Evolve의 생물 종족, 인구·직업, 종교, 다중 우주, 전술 전투 전체를 구현한 것은 아니다.
