# Evolve Original Desktop 1.4.10

This is an unofficial personal desktop package of Evolve Idle.
Original game: Peter Motschmann and the Evolve contributors.
Original project: https://github.com/pmotschmann/Evolve
Original game release: 1.4.10
Source snapshot: 3436358dcd03d9f9e071d51ea071e0a78c0322e4

Evolve source and bundled compiled game code are governed by the Mozilla Public
License 2.0. The complete, unmodified upstream source and license are available at:
https://github.com/kingjow363-stack/game/tree/main/evolve-desktop/upstream
A separate Evolve-Original-Source download also accompanies the Windows build.
The original license notices are preserved in upstream/LICENSE and web/LICENSE.

Desktop adaptation: local copies of the exact CDN library versions, an offline
Lato font, an Electron window, stable local save storage, periodic atomic backups, recovery controls, and local wiki windows.
The original game scripts, CSS, worker, balance, text and game-save format are
unchanged. Generated HTML replaces external dependency URLs and removes the
external Google Analytics loader. No game mechanics are replaced with EXO code.
External community/support links open the system browser only when clicked.

Runtime library licenses are included alongside their files in web/vendor;
Lato's license is in web/vendor/lato/LICENSE. Bundled upstream third-party
license notices remain with their original library/font files.

The separate EXO Industries project and saves remain available and unchanged.
